# `web/` directory

Historical **browser UI** lived here as static `index.html`. That file was **removed** in favour of **`frontend/`** (Next.js 15 + App Router).

Use this folder for:

- Static assets referenced by tooling (future)
- One-off prototypes that should not clutter `frontend/`

**Current production browser path:** run Python API → run Next app — see [README.md](../README.md) and [docs/FRONTENDS.md](../docs/FRONTENDS.md).
